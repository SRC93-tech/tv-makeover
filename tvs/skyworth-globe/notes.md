# Skyworth globe (MediaTek MT5891, Android TV 8.0.0)

- **ADB over TCP only (no Wireless debugging)**: Android 8 has no Wireless debugging menu; enable USB debugging in Developer options and connect directly on port `5555`. **Important**: full reboot resets `adb_enabled=0` on this firmware, so USB debugging must be toggled back on in Developer options after any reboot.
- **`TV_INPUT_HARDWARE` guard**: `com.google.android.leanbacklauncher.partnercustomizer` (`ArcherLeanbackCustomizer2`) requests `android.permission.TV_INPUT_HARDWARE`. Do **not** disable it (`disable.ps1` automatically skips it).
- **Load-bearing vendor packages (keep enabled)**: `com.mediatek.agent`, `com.mediatek.dmagent`, `mtktvapi.agent`, `com.mediatek.wifi`, `com.mediatek.partner.netflix`, `com.coocaa.factory`, `com.google.android.boot.appsplashscreen`, `com.mediatek.wwtv.mediaplayer`, `com.mediatek.wwtv.tvcenter`, `com.mediatek.tvinput`, `com.mediatek.tunerservice`, and `com.google.android.apps.inputmethod.hindi` (referenced as `selected_spell_checker`).
- **Audio streams**: `STREAM_SYSTEM` speaker volume is `0`, while `STREAM_MUSIC` is active — DreamOS `UiSounds` (`USAGE_MEDIA`) plays cleanly at the TV's media volume.
- **Measured memory & CPU**:
  - Stock Home (`before`): `MemFree` ~55 MB (`55,080 kB`), `tvlauncher` 1.8% CPU, `backdrop` 1.7% CPU (78k minor faults).
  - DreamOS + debloat (`after`, same session): `MemFree` ~160 MB (`163,940 kB`), `tvlauncher`, `tvrecommendations`, `leanbacklauncher.recommendations`, and `backdrop` completely gone from memory/CPU; `com.gathin.tvhome` ~66 MB PSS in foreground.
- **Weather, wallpaper, top-bar & sunset overlay (DreamOS build)**: Added Open-Meteo current weather + sunrise/sunset time-of-day solar sky tint (`Weather.java`, `Sky.solarIntensity`, `SkyView.setSolarConfig`) + live vector weather condition icons (sun, moon, partly cloudy, cloudy, fog, rain, snow, thunderstorm) across Home and `ClockDream`. Enabled top-bar **Inputs** and **Wi-Fi** pills (`header_pills`) with live green/red connection indicator + `ic_wifi_off` fallback, 12-hour AM/PM clock + inline date (`EEE, d MMM`), personalized greeting, and on-demand **App library** (`app_library`). Single-tap on the Settings gear opens the launcher Settings menu (including *TV system settings* and *Launcher settings*; long-press removed). Pushed 8 Alpine & Nature wallpapers (`15` min rotation, `12%` dim) from `build/dreamos-alpine-wallpapers`.
- **Build note (Android 8 / Windows)**: Set `buildToolsVersion '36.0.0'` if SDK `34.0.0` is not installed locally alongside `platforms/android-34`.
