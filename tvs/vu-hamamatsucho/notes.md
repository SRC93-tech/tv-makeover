# Vu Smart 2K ATV4 (`hamamatsucho`, `m5621`, Android TV 9 / SDK 28)

- **Hardware profile**: `1280x720` (`213 dpi`), `~925 MB` total RAM (`200 MB` swap). Heavily memory-constrained; keep `reduced_motion: true`, `ambient_glow: false`, `advanced_effects: false`, `wallpaper_dim: 0`, and global animation scales at `0.5` (`window_animation_scale`, `transition_animation_scale`, `animator_duration_scale`).
- **Debloat & restore**: Disabled 22 non-core packages (`tvrecommendations`, `leanbacklauncher.recommendations`, `cvte.startpartnertv*`, `fusion.android.tv.demo`, `backdrop`, `bugreportsender`, `feedback`, `play.games`, `videos`, `music`, `talkback`, `setupwraith` after verifying Wi-Fi owner is `android.uid.system:1000`, `katniss`, `speech.pumpkin`, `tts`, `syncadapters.calendar`, `syncadapters.contacts`, `providers.calendar`, `providers.userdictionary`, `printspooler`, `dreams.basic`) plus `com.google.android.tvlauncher` once replacement Home was installed. Keep `com.mediatek.*`, `com.cvte.autobacklight`, `com.cvte.fac.menu`, `com.mstar.*`, `com.google.android.leanbacklauncher.partnercustomizer`, `com.google.android.apps.mediashell`, and `com.android.vending` enabled. Re-enable `katniss`, `speech.pumpkin`, and `tts` if voice search is ever wanted back.
- **Ethernet static-IP bug fix**: If Ethernet (`eth0`) is configured as `Static` with blank fields while disconnected, `IpClient.eth0` crash-loops every ~16 ms (`Null LinkAddress given`), pinning `EthernetService`, `HeapTaskDaemon`, and `netd` at ~45%–52% whole-TV idle CPU. Switching Ethernet **IP settings** to **DHCP** drops whole-TV idle CPU from `47.0%–52.2%` down to `~2.2%`.
- **Screensaver**: Switched `screensaver_components` from `com.google.android.backdrop/.Backdrop` to `com.gathin.tvhome/.ClockDream`.
- **App compiler state**: Main streaming apps (`YouTube`, `Netflix`, `Prime Video`, `Hotstar`, `JioTV+`, `VLC`) are already `speed-profile` compiled (`1.3 GB` `/data` free).
- **Measured three-stage progression (`bench.py`, 12 keys + cold starts)**:
  - Stock `tvlauncher` (before): p95 response `95.6 ms`, p50 movement `1,224 ms`, jank `4.57%` (`61/1334` frames), cold start `1,517 ms` p50 (`2,273 ms` p95), idle TV CPU `52.2%`, idle launcher CPU `10.8%`, `MemAvailable` ~`226 MB` (swap full).
  - Personalized `com.gathin.tvhome` + 13-pkg debloat + `0.5x` scales + `reduced_motion`: p95 response `31.6 ms`, p50 movement `204 ms`, jank `1.22%` (`1/82` frames), cold start `1,056 ms` p50, idle TV CPU `47.0%`, idle launcher CPU `0.0%`, `MemAvailable` ~`255 MB`.
  - After Ethernet DHCP fix + Assistant/voice (`katniss`, `speech.pumpkin`, `tts`) & sync debloat: p95 response `27.3 ms` (**3.5x faster**), p50 movement `198 ms` (**6.2x faster**), jank **`0.0%` (`0/86` frames)**, cold start **`973 ms` p50**, return-to-home **`80 ms` p50**, idle TV CPU **`2.2%`**, `MemAvailable` ~`269–283 MB` (swap freed).
